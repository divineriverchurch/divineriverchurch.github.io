# Divine River Church Website

## Version 1 Content and Asset Inventory

Document Version: 1.0
Project: Divine River Church Website
Scope: Version 1 Public Website

## 1. Purpose

This document tracks all content, information, images, media links and external service details required to build and publish Version 1 of the Divine River Church website.

The inventory should be updated throughout development.

Each item should use one of the following statuses:

| Status           | Meaning                                                            |
| ---------------- | ------------------------------------------------------------------ |
| Received         | The information or file has been provided                          |
| Approved         | The church has reviewed and approved it for publication            |
| Needs correction | The item exists but requires correction or replacement             |
| Pending          | The item has not yet been provided                                 |
| Not required     | The church has decided that the item will not be used in Version 1 |

Production deployment should use approved content wherever possible.

The developer must not invent church information to fill missing sections.

# 16. Image Quality and Publication Checklist

Before any image is added to the production website, confirm:

| Check                  | Requirement                                               |
| ---------------------- | --------------------------------------------------------- |
| Ownership / permission | Church has permission to publish the image                |
| Resolution             | Image is sufficiently high resolution                     |
| Composition            | Image works for its intended layout                       |
| Subject approval       | Required people have approved publication where necessary |
| File name              | Descriptive file name is used                             |
| Optimisation           | Web-ready version has been generated                      |
| Alt text               | Appropriate text description is available where required  |

Example preferred filenames:

`divine-river-church-worship-service.jpg`

`divine-river-church-exterior.jpg`

`youth-ministry-2026.jpg`

Avoid filenames such as:

`IMG_4823.jpg`

`DSC00192.jpg`
