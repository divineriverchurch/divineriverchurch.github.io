# Divine River Church Website

Divine River Church public website.

## Version

Version 1 - Public Website

## Architecture

The website is generated as a static site using:

- Python
- Jinja2
- HTML
- CSS
- Minimal JavaScript
- JSON structured content

The generated website is stored in `dist/`.

## Production

Source control: Git/GitHub

Hosting: Cloudflare Pages

Media: YouTube and YouTube Live

Maps: Google Maps

Communication: WhatsApp, telephone, email and approved social-media platforms.

## Version 1 Scope

Pages:

- Home
- About
- Ministries
- Sermons
- Programmes
- Events
- Give
- Contact

Version 1 does not contain:

- a database
- member accounts
- authentication
- a custom backend
- internal payment processing
- a church administration system
